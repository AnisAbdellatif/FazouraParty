# Words a public room will not show (PROTOCOL.md §3.5, Fazoura.Moderation.Profanity).

# One entry per line; blank lines and lines starting with # are ignored. Matching is
# case-, accent- and leetspeak-insensitive (0→o, 1→i, 3→e, 4→a, 5→s, 7→t, @→a, $→s),
# and repeated letters are collapsed ("fuuuck"), so list the plain spelling.
#
#   word     matches as a whole word only, so "ass" does not catch "assassin"
#   *stem    also matches inside other words and across separators ("f.u.c.k",
#            "fuckface") — only for strings that are never part of an innocent word
#   !word    an innocent word a stem would otherwise catch ("Scunthorpe"): a token
#            equal to it is never matched against anything
#
# Leave out anything that is also a fair quiz answer ("Hitler" in a history quiz,
# "dog" in Arabic): an answer the game marks correct is never masked, but a player's
# name or a wrong answer that happens to be one would be.
#
# This is a floor, not a filter that thinks: it stops the obvious, and the report
# button and the host's "remove" are what handle the rest. Add to it freely; a
# restart picks it up (the list is compiled in).
